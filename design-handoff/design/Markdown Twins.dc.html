Markdown twins

Every HTML page has a Markdown version at the same path plus .md, so agents and people can fetch a page as plain text. The HTML and the twin are rendered from the same registry objects at build, and the frontmatter keys are stable.

Controls on every detail page

  • Copy as MarkdownCopies the twin's full text. The label switches to "Copied" for about two seconds and is announced politely.
  • View .mdOpens the raw file, served as text/markdown; charset=utf-8.
  • Open in Claude / ChatGPTOpens the assistant with the prompt Read <md URL> and use it for this session. Localized pages translate the prompt and keep the URL.
