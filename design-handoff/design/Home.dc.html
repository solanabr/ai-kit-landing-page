§ 06

FAQ

Does it work outside Claude Code?[+]

Yes. Claude Code is the primary target. The --agents flag installs it for Codex, opencode and other agents, and no-install mode works in any agent that can fetch a URL.

What does it install, and where?[+]

Everything goes into the project you run it from: agents, commands, skill packs and the firewall under .claude/, plus the MCP server configuration. Four skill packs are installed by default; add others with bash .claude/bin/skills.sh add <id>.

Does it send my code anywhere?[+]

The kit is configuration files in your repository. It has no account and no server of its own. Your agent still talks to its model provider, and each MCP server receives only the requests your agent sends to it. You can turn any MCP server off.

How do updates work?[+]

Run the install command again from your project's root. Skill packs are pinned to commits, so a pack only changes when a new kit release moves its pin after a fresh scan.

What is "no install" mode?[+]

A short prompt you paste into any agent. It points the agent at aikit.superteam.codes/CLAUDE-solana.md, which it reads for that session. Nothing is written to your project.
