§ 06

FAQ

Funciona fora do Claude Code?[+]

Sim. O Claude Code é o alvo principal. A flag --agents instala o kit para Codex, opencode e outros agentes, e o modo sem instalação funciona em qualquer agente capaz de buscar uma URL.

O que ele instala, e onde?[+]

Tudo vai para o projeto em que você executa o comando: agentes, comandos, pacotes de skills e o firewall em .claude/, além da configuração dos servidores MCP. Quatro pacotes de skills são instalados por padrão; adicione outros com bash .claude/bin/skills.sh add <id>.

Ele envia meu código para algum lugar?[+]

O kit é um conjunto de arquivos de configuração no seu repositório. Ele não tem conta nem servidor próprio. Seu agente continua falando com o provedor do modelo, e cada servidor MCP recebe apenas as requisições que o agente envia a ele. Você pode desativar qualquer servidor MCP.

Como funcionam as atualizações?[+]

Execute o comando de instalação de novo na raiz do projeto. Os pacotes de skills são fixados em commits, então um pacote só muda quando uma nova release do kit move o commit após uma nova verificação.

O que é o modo "sem instalar"?[+]

Um prompt curto que você cola em qualquer agente. Ele aponta o agente para aikit.superteam.codes/CLAUDE-solana.md, que é lido durante aquela sessão. Nada é gravado no seu projeto.
